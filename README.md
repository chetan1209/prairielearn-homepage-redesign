# PrairieLearn Homepage Redesign

An independent, interactive homepage concept for [PrairieLearn](https://www.prairielearn.com/). The redesign keeps PrairieLearn's academic and open-source identity while making the product experience more visual and easier to understand.

## Highlights

- Interactive randomized assessment with grading feedback
- Visual question-authoring workflow
- Interactive course journey and assessment-type previews
- Responsive layouts for desktop and mobile
- Institutional adoption metrics and animated university logo strip
- Editorial research, open-source, accessibility, security, and support sections

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Production build

```bash
npm run build
```

## Stack

React 19, TypeScript, Vinext/Vite, Tailwind CSS, Radix UI, and Lucide icons.

## Note

This is a redesign concept, not the official PrairieLearn website. Product facts and institution marks are referenced from PrairieLearn's public website.
